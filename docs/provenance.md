# Archive provenance and omissions

## Original research

Author: Ozan Safak Kocak. MSc Data Science & Society, Tilburg University, 2026.

Thesis title: Evaluating Image Classification Performance of RF and CNN on Synthetic Image Data Generated by CWGAN-GP and DDIM. Submitted 25 May 2026.

The local thesis project contained 132 notebooks and 17 Python scripts. All 149 are retained here, including duplicates, exploratory attempts, hardware variants, and files named “final”. A deeper scan also found 73 Jupyter checkpoint notebooks; 34 contained code hashes absent from the regular/main-plus-helper inventory. After removing one exact duplicate among those candidates, 33 additional autosaves were preserved separately under `archive/recovered-autosaves/`. Some have no surviving regular counterpart; their status as final or intermediate code is unknown. A separate helper folder contained seven more notebooks; those were excluded from this public collection to avoid mixing helper copies with the main project. Third-party textbook repositories and unrelated coursework were also excluded.

## Completeness statement

The author reports accidentally deleting some original working files. The precise scope of deletion has not been established, and it is not known whether deleted material consisted only of unsuccessful trials or included necessary final-run files. The surviving collection covers the main research stages, but this repository is not certified as a complete, executable record of every final experiment.

No deleted source has been silently reconstructed or presented as original. Exact final-run provenance should be established by matching code versions, parameters, checkpoints, and outputs with the thesis before claiming full replication.

## Publication preparation, October 2026

- Original research files are under `experiments/` with their internal relative paths retained.
- Notebook outputs, execution counters, and per-cell runtime metadata were cleared; public notebook kernel metadata is generic. Code and markdown remain, except for personal local/cluster path-prefix anonymization.
- Python source was retained with the same personal-path anonymization. Algorithms, training loops, parameters, and evaluation logic were not rewritten for this publication.
- `docs/source-manifest.json` records each source-relative location, source code hash, and final published-file hash. Source code hashes for notebooks refer to concatenated code cells, while published hashes cover the sanitized file bytes.
- `results/classification_results.csv` is an unchanged saved result table checked against the thesis.
- README, navigation/method notes, chart generation, validation, and GitHub automation are newly added packaging work, prepared with AI assistance. They are not presented as original thesis experiments.

## Excluded assets

No dataset images, synthetic sample arrays, processed arrays, feature arrays, or thousands of saved model/checkpoint files are uploaded. The private local code backup remains separate. Credential files, SSH/login material, planning/chat documents, personal student identifiers, and the full thesis PDF are excluded. The original source folder and local backup are unchanged.

Dataset providers and model/method references retain their own attribution and terms. References already present in the archived code are preserved. No new blanket licence is asserted over third-party material.

## Validation boundary

All research notebooks were parsed and found to contain code; all 17 `.py` files parse as Python. The added archive checks verify file counts/hashes, cleared notebook outputs, absence of selected sensitive patterns, and result-table structure. No original ML experiment was retrained or fully re-executed, and no current dependency environment is claimed to replicate the reported results.
